# Firetier engineering instructions

Before investigating a similar failure, read `docs/ENGINEERING_LESSONS.md`, `docs/REGRESSION_HISTORY.md`, and `docs/DEBUGGING_GUIDE.md`. Reproduce in an isolated home and target, add a regression, run related integration coverage, and verify the correction through the actual desktop application. Record symptoms, cause, correction and evidence in the history. Distinguish fixture, packaged and live-game observations.
