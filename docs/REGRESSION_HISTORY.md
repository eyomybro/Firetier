# Regression history

## Switching client presets in Merge mode

Switching from No Textures to Max FPS retained the enabled texture override. Switching renderers left multiple preference flags true. The presets omitted settings they needed to turn off, and Merge correctly preserved the older values. Max FPS now disables the texture override and each renderer preset sets all three preferences. The regression `test_merge_switches_exclusive_preset_settings` reproduced four failing transitions before the correction. It checks the resulting values, preservation of an unrelated setting, and all six presets through the app's Apply service.

Diagnostics now reads bounded excerpts from recent Roblox Player logs. It names the observed session, reports matching preset values, identifies explicit denials and shows a recognized shader backend. `test_player_evidence_distinguishes_config_denial_and_backend` covers an incomplete newer launch and a renderer preference that the logged session denied.

Windows debugging milestone • November 2026. Each row identifies the symptom, underlying fault, correction and a test that can recognize a recurrence. Test names refer to the files in `tests/`. The original baseline passed 30 tests. The added fault fixtures failed against the original engine or desktop where indicated in the milestone report.

| Symptom or recurrence signal | Root cause | Correction and verification |
|---|---|---|
| Restore reports a checksum mismatch after a healthy target has already changed | Digest comparison happened after replacing the destination | Verify the staged copy before replacement and clean it on failure. `test_corrupt_backup_never_replaces_current_file` checks original bytes. `capture_windows.py` repeats the failure through the Backups tab. |
| One malformed manifest breaks the Backups tab, or an interrupted backup disappears silently | Listing assumed decoded JSON was a complete mapping and skipped missing manifests | Validate ID, required fields, timestamp, absolute JSON destination, existence state and checksum format. Keep the directory and expose the fault in Diagnostics. `test_backup_index_isolates_bad_metadata` exercises a good entry beside three bad ones. |
| Renaming a copied profile overwrites another | Listing used the filename as ID, opening used the embedded ID | Use the filename consistently when opening an existing local profile, and assign fresh IDs to imports. `test_identity_comes_from_file` opens and renames both copies. |
| Repeated deletes can overwrite earlier trash | Destination names included only whole seconds | Give every trash entry a unique suffix. `test_repeated_delete_preserves_both_versions` freezes the clock and verifies both files. |
| A damaged profile prevents other profiles from loading or changes the meaning of a rule | Container-valued games and timestamps reached lookups/conversion unchecked. Truthiness converted the string false into enabled | Validate version, game, timestamps, rule scalars and boolean state. Reject the malformed file while retaining it on disk. `test_bad_profile_isolated_and_original_preserved`, `test_import_validation`. |
| Deep JSON or long numeric inputs escape normal import handling | The parser and later recursive consumers accepted different nesting limits, and numeric conversion could raise during rule classification | Limit depth, normalize numeric conversion failures, reject nonstandard JSON constants and cap numeric strings. `test_import_validation`, `test_large_number_is_invalid_rule`. |
| An apparently saved profile vanishes on reload | Output expansion could exceed the reader's byte limit | Check the actual serialized size before atomic replacement. `test_saved_profiles_roundtrip_with_size_limit` exercises a reduced boundary. |
| An archived replacement profile can clear a target via the engine | The GUI blocked Apply, but the write service still accepted Replace with empty flags | Enforce archive-only status inside the service for both modes and retain it on reimport. `test_unsupported_replace_cannot_clear_target`, `test_historical_compatibility_fixtures`. |
| Arbitrary text is counted as an asset ID, or a scan ignores its budget | Recognition accepted an arbitrary substring and the key scan ran independently of the node budget | Match the asset reference format and stop traversal when the budget is spent. `test_asset_identifier_and_budget`. Matched IDs still represent a heuristic. |
| Opening an archive shows a plausible rendered result | The renderer turned an unsupported profile into an empty flag set | Label the unavailable result, clear its image, and restore the rendered comparison on the next supported profile. `test_archived_assets_have_explicit_preview_state`. |
| Startup fails on malformed preferences, or silently overwrites a damaged file | Unvalidated values reached Tk, and read/write failures were discarded | Validate known settings, keep damaged originals, rotate a previous configuration, recover at startup and report persistence failures. `test_invalid_settings_types_and_defaults`, `test_corrupt_settings_recover_previous_and_preserve_original`, `test_preferences_write_failure_visible`. |
| Cancelling New after declining to save leaves an edited profile marked clean | The leave prompt cleared the dirty flag before navigation committed | Keep the dirty state until the profile actually changes. `test_cancelled_navigation_preserves_dirty_flag`. |
| Flag name field collapses at 1000 px and the profile description is truncated | The editor packed every field and six buttons into one row. Description wrapping used a fixed larger width | Put actions on their own row, wrap to the available width and enable horizontal table scrolling. `test_editor_field_usable_at_minimum_width` plus [before](evidence/before-flags.png) and [after](evidence/after-flags.png). |
| Reopening Preview rebuilds identical images on the UI thread | Both panes recomputed the full scene on every refresh | Retain up to six renderings and update changed panes. `test_preview_reuses_identical_render`, `stress_windows.py`. |
| Long diagnostic output is truncated, a slow check freezes the UI, or Windows query failure is invisible | Fixed table cells, synchronous system calls and a fallback that converted a failed query into an empty process set | Expose the selected check's full text, collect on a worker, cancel pending UI polling on close and display query failures. `test_diagnostic_selection_exposes_full_detail`, `test_unavailable_process_check_reported`, delayed-check stress probe. |
| Two cooperating writers can operate on the same target, or an edit during backup is lost | Atomic replacement protected a single file write but did not serialize the surrounding read/backup/write sequence | Use Windows named mutexes for app workspaces and target operations, recheck the target after backup. `test_concurrent_apply_and_restore_preserve_target`, `test_concurrent_external_edit_during_backup`. |
| Low-memory import exits the operation without actionable feedback | Import assumed it could allocate the input and decoded document | Bound reads and return a specific memory error. The Windows job-object test induces real allocation failure. `test_atomic_write_handles_memory_error` covers a separate interrupted write. |

The byte-level kill test also passed. Killing the writer at its flush boundary left the committed destination readable and byte-identical. A crash can leave a staging file. No hours-long leak or power-loss durability guarantee follows from this run.
